# 🎮 Pacman Game - Object-Oriented Programming Project

## Overview

This project is a recreation of the classic **Pacman Game**, developed as an academic project to demonstrate the practical implementation of **Object-Oriented Programming (OOP)** principles. The game provides an engaging and interactive environment where players control Pacman, collect points, avoid enemies, and navigate through a maze.

The primary goal of this project was not only to develop a functional game but also to showcase the effective use of OOP concepts such as **Encapsulation, Inheritance, Polymorphism, and Abstraction** within a real-world application.

## 🎯 Object-Oriented Programming Concepts Implemented

### 1. Encapsulation
Data members and functions were encapsulated within classes to ensure data security and controlled access.

Examples:
- Player attributes (score, position, lives)
- Ghost attributes and movement logic
- Maze and game-state management

### 2. Inheritance
Inheritance was used to establish relationships between base and derived classes.

Examples:
- Base `Character` class
- Derived `Pacman` class
- Derived `Ghost` class

This approach reduced code duplication and improved scalability.

### 3. Polymorphism
Polymorphism was implemented to allow different objects to respond differently to the same operation.

Examples:
- Different movement behaviors for ghosts
- Function overriding for game entities
- Dynamic object interactions

### 4. Abstraction
Complex game logic was hidden behind simple interfaces, allowing users and developers to interact with objects without needing to understand internal implementations.

Examples:
- Movement handling
- Collision management
- Score calculation system
- Game-state transitions
